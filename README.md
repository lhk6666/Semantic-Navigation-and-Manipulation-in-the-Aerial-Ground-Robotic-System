# Heterogeneous Robot Collaboration Framework

This repository contains a collection of research projects focused on LLM-based robot systems.

## Project Overview

Currently, the main and completed project in this package is:

### [llm_multiagent](scripts/llm_multiagent/)

**Hierarchical Language Models for Semantic Navigation and Manipulation in Aerial-Ground Robotic System**  
_Start date: October 2024_

This project explores a novel hierarchical framework where multiple Large Language Models (LLMs) collaborate to plan and control a heterogeneous robotic system consisting of a UAV and a quadruped robot. The system performs high-level semantic reasoning and low-level task execution, including navigation and manipulation.

Please refer to the [llm_multiagent README](scripts/llm_multiagent/README.md) for detailed commands on running the system.
